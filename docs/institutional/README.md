# Institutional Track

This directory converts SABLE's evidence into external research, company, platform, sponsorship, and strategic-buyer opportunities.

## Active

- `AGENT_EVALUATION_SCIENCE_2026_EXTENDED_ABSTRACT.md` — current 2-page research submission draft.
- `AGENT_EVALUATION_SCIENCE_SUBMISSION_CHECKLIST.md` — evidence, manuscript, and OpenReview gates.
- `AGENT_EVALUATION_SCIENCE_OUTREACH_NOTE.md` — concise institutional fit/query note.
- `INSTITUTIONAL_CONVERSION_SPRINT_20260916.md` — current execution sprint.
- `INSTITUTIONAL_OPPORTUNITY_LEDGER.md` — canonical target/status ledger.

## Operating rule

Institutional status is earned by external action. A public call, draft, or application alone does not count as institutional opportunity. Preserve receipts for submissions, responses, interviews, invitations, sponsorships, collaborations, acceptances, and offers.
