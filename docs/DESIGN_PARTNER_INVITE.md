# SABLE Design Partner — One Real Execution

**One real execution. One independently readable effect. One verifiable receipt.**

You do not need to share credentials, private traces, or customer data.

### What we need

Run one harmless Agent/tool action in a runtime you already use. The action should create a state change that can be independently read afterwards.

Examples:

- a sandbox GitHub issue comment
- a disposable database row
- a test record in a public or isolated endpoint

### What you return

Submit the machine-readable execution evidence as a pull request under `submissions/` using the SABLE Reliability Record format:

`docs/EXTERNAL_RELIABILITY_RECORD_SUBMISSION_V0.1.md`

SABLE will independently validate the cited execution provenance and artifact. Maintainers retain the final promotion decision.

The goal is not another benchmark score. The goal is to test whether a real agent execution can be converted into an independently verifiable reliability receipt.
